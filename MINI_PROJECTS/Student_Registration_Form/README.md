# Student Registration Portal

A simple responsive student registration mini project built using:

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Features

- Student registration form
- Email, website and direct student photo upload
- Student photo is mandatory (registration is blocked without it)
- Gender selection
- Custom skills: type any skill, add it with the Add Skill button or Enter key
- Skills appear as removable tags; duplicates (case-insensitive) are not allowed
- Form validation
- Student photo preview before submission
- Clear Form resets all fields, the photo preview, skills and messages
- Uploaded photos and skills are saved in browser LocalStorage
- Enrolled-student directory
- Delete student option
- Data remains after page refresh using LocalStorage
- Responsive layout

## How to Run

Open `index.html` in a browser.

For the best development experience, open the folder in VS Code and use the Live Server extension.

Or Run the Student Registration Portal through this link - https://tejasva26.github.io/Mern/
